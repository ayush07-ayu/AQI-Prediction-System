# India Pollution Analytics & AQI Prediction

A data analytics and machine learning project focused on analyzing pollution trends across Indian cities and predicting future AQI levels using environmental and human activity data.

## Features
- AQI Analysis
- 3D Data Visualization
- ML-based AQI Prediction
- Pollution Trend Insights
- Recommendation System

## Tech Stack
- Python
- Pandas
- Plotly
- Scikit-learn
- Streamlit
